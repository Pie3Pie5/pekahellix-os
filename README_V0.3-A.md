# Pekahellix OS — V0.3-A

## Objectif
Première adaptation mobile : écran de connexion.

## Test rapide
1. Ouvrir `index.html` sur ordinateur.
2. Vérifier que l'écran desktop n'a pas changé.
3. Ouvrir les outils développeur du navigateur.
4. Activer un appareil mobile (360×800, 390×844 ou équivalent).
5. Vérifier : logo, titre, champs, bouton et message d'erreur.
6. Tester la connexion avec les identifiants de démonstration existants.
7. Tester le clavier virtuel si possible sur un vrai smartphone.

## Critères de validation
- Aucun scroll horizontal.
- Aucun zoom automatique lors de la saisie sur iPhone.
- Champs et bouton facilement utilisables au doigt.
- Le bouton reste accessible lorsque le clavier apparaît.
- Le rendu desktop reste inchangé.

## Important
L'authentification actuelle reste provisoire. Les identifiants présents dans le JavaScript devront être remplacés par une authentification serveur avant publication.
