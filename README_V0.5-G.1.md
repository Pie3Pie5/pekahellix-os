# Pekahellix OS V0.5-G.1

Avant de tester le bouton « Envoyer mes réponses anonymement », exécuter `SUPABASE_V0.5-G.1.sql` dans l’éditeur SQL Supabase.

La table créée ne contient aucun identifiant utilisateur, nom ou e-mail. Les utilisateurs authentifiés peuvent uniquement insérer une réponse et ne peuvent pas relire la table. Une fonction d’agrégation réservée aux administrateurs est fournie pour préparer une restitution collective.
