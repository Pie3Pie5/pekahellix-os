# Pekahellix OS — V0.3-B

## Objectif
Transformer l'accueil « Bureau OS » en véritable tableau de bord mobile, tout en conservant l'interface desktop.

## Modifications
- Barre supérieure adaptée au smartphone.
- Accueil mobile avec cartes tactiles pour les 3 outils.
- Flèche d'accès visuelle sur chaque outil.
- Barre de navigation inférieure mobile avec les 3 outils.
- Gestion des zones sûres iOS/Android (`safe-area-inset`).
- Fenêtres d'applications adaptées aux écrans mobiles.
- Expérience desktop conservée au-delà de 600 px.

## Tests recommandés
1. Se connecter sur smartphone.
2. Vérifier le nom utilisateur et l'horloge dans la barre supérieure.
3. Vérifier les 3 cartes : Gestion du Temps, Communication, Cybersécurité.
4. Ouvrir chaque outil depuis une carte.
5. Revenir à l'accueil avec « Retour accueil ».
6. Ouvrir chaque outil depuis la barre inférieure.
7. Vérifier qu'il n'y a aucun défilement horizontal.
8. Tester en portrait sur un petit smartphone.
9. Vérifier que le contenu reste accessible avec le clavier ouvert.
10. Vérifier que la version desktop reste inchangée.

## Validation
Si les tests sont satisfaisants : **V0.3-B validée**.
