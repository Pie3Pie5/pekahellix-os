# Test V0.4.1

Cette version corrige la navigation inférieure de la PWA sur smartphone.

## Mise à jour GitHub Pages
Remplacer dans le dépôt les fichiers `style.css`, `script.js` et `sw.js` par ceux de cette version. Vous pouvez aussi téléverser l'ensemble des fichiers de la V0.4.1.
