# Pekahellix OS — V0.5-F.5

## Nouveautés
- Splash de démarrage : le logo Pekahellix occupe l’écran à l’ouverture, marque une courte pause puis effectue un zoom arrière fluide jusqu’à sa position sur l’écran d’authentification.
- Respect de `prefers-reduced-motion` : l’animation est neutralisée pour les utilisateurs qui limitent les animations système.
- Le logo du header est désormais cliquable/tactile.
- Un clic ouvre une vue agrandie sur fond sombre afin de lire facilement le slogan « 3 piliers pour accompagner votre proximité ».
- Fermeture de la vue agrandie par le bouton ×, un clic sur l’arrière-plan ou la touche Échap.
- Cache PWA et numéro de build passés en 0.5-F.5.

## Inchangé
- Supabase, authentification, profils, rôles, droits d’accès et cycle de vie des comptes.
- Affichage/masquage des mots de passe.
- Correctif du cache des appels API Supabase.
